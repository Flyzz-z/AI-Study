# 卷积神经网络（CNN）简要总结

## 关键概念
- 卷积层（Conv2d）：用可学习卷积核在空间维度滑动，对局部区域加权求和，参数共享与局部连接减少参数并带来平移不变性。
- 激活函数（ReLU）：将负值置零，提供非线性能力并缓解梯度消失。
- 池化层（MaxPool2d）：下采样，常用 2×2、步幅 2，降低尺寸与计算量，增强小幅变形鲁棒性。
- 展平（Flatten）：把 `N×C×H×W` 变为 `N×(C*H*W)`，进入全连接层。
- 全连接层（Linear）：整合全局特征，输出类别 logits；分类任务与 `CrossEntropyLoss` 搭配。

## 结合 `cnn.py` 的结构说明
- 模型：`LeNet`（经典小型 CNN）
  - 卷积块 1：`Conv2d(1→6, k=5)` → `ReLU` → `MaxPool2d(2,2)`
  - 卷积块 2：`Conv2d(6→16, k=5)` → `ReLU` → `MaxPool2d(2,2)`
  - MLP：`Flatten(16×4×4=256)` → `Linear(256→120)` → `ReLU` → `Linear(120→84)` → `ReLU` → `Linear(84→10)`
- 维度流（MNIST 1×28×28）：
  - 28×28×1 → Conv5×5 → 24×24×6 → Pool → 12×12×6
  - 12×12×6 → Conv5×5 → 8×8×16 → Pool → 4×4×16
  - 展平为 256 → 全连接输出 10 类 logits

## 网络流程
1. 输入：单通道灰度图 `1×28×28`。
2. 卷积 1：`Conv2d(1→6, k=5)` 提取基础边缘/纹理特征。
3. 激活 1：`ReLU` 引入非线性，保留正响应。
4. 池化 1：`MaxPool2d(2,2)` 下采样，尺寸 `24×24×6 → 12×12×6`。
5. 卷积 2：`Conv2d(6→16, k=5)` 提取更高层次特征模式。
6. 激活 2：`ReLU`。
7. 池化 2：`MaxPool2d(2,2)` 下采样，尺寸 `8×8×16 → 4×4×16`。
8. 展平：`Flatten` 将 `4×4×16` 展平成 `256`。
9. 全连接 1：`Linear(256→120)`，聚合全局特征。
10. 激活 3：`ReLU`。
11. 全连接 2：`Linear(120→84)`。
12. 激活 4：`ReLU`。
13. 全连接 3：`Linear(84→10)`，输出 10 类 logits（用于 `CrossEntropyLoss`）。

## 数据与训练流程
- 预处理：`ToTensor()` + `Normalize(mean=0.1307, std=0.3081)`。
- DataLoader：训练集打乱、测试集不打乱；常用批大小 64。
- 训练步骤：清梯度 → 前向 → 交叉熵损失 → 反向 → 优化器更新。
- 评估：`model.eval()` + `torch.no_grad()`，计算平均损失与准确率。

## 实践建议
- 合理选择核/步幅与 Padding，权衡感受野与信息保留。
- 使用 logits + `CrossEntropyLoss`；可配合 `BatchNorm`、权重衰减与数据增强提升稳定性与泛化。
- 用“批均值损失”便于固定学习率；批大小按显存与稳定性选择（如 32/64/128）。
